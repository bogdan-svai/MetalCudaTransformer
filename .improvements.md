# Improvements

## Native verification

Restore the Metal Toolchain and run the complete development test suite, native
builds and GPU result checks. The latest publication checks covered command
startup, source analysis, source generation, command installation and removal.
They did not verify a fresh native build or GPU execution.

## Installation

Test the installer on a clean Apple Silicon Mac with Python 3.11 or later.
Verify dependency installation, libclang loading, command setup and a native
build outside the source directory. Check each supported Xcode version.

## Compiler

Complete the migration from textual lowering to semantic IR. Preserve source
locations and clear diagnostics for unsupported constructs. Remove older paths
only after their replacements pass the development regression suite.

## Host loops

Measure comparable CPU and GPU execution costs before adding a profitability
threshold. Keep automatic offload disabled by default. Extend the compilation
driver and Makefile integration after cache invalidation is verified.

## Performance

Collect current measurements with hardware, toolchain, input sizes, cache state,
warmups and sample counts recorded. Separate frontend, compilation and execution
costs. Check results against a CPU implementation before reporting timings.

## Distribution

Choose a license for the original code and complete the dependency and source
provenance review. Keep the development tests available outside this minimal
distribution.
