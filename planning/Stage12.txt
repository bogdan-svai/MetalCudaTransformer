# SOFTWARE REQUIREMENTS SPECIFICATION (SRS)
# SYSTEM LAYER: STAGE 12 - CUDA RUNTIME API COMPATIBILITY
# -----------------------------------------------------------------------------

## 1. OBJECTIVE
Stage 12 expands MCU's support for the main CUDA Runtime API used by ordinary
CUDA programs that include `cuda_runtime.h`.

This is not a library-adapter stage. It targets CUDA's primary runtime surface:
device selection, device properties, events, error behavior, occupancy helpers,
and memory edge cases. The result should make more CUDA code compile without
source edits before Stage 13 freezes tooling contracts.

## 2. CURRENT GAP
MCU already supports kernels, memory allocation/copy, memset, streams, async
copies, shared memory, atomics, device helpers, Makefile integration, and a
cuBLAS SGEMM adapter. Many CUDA programs still fail because they use common
runtime calls around otherwise supported kernels:

* query device count and properties before choosing launch geometry;
* time work with `cudaEvent*`;
* inspect errors with `cudaPeekAtLastError`;
* call `cudaDeviceReset` during cleanup;
* use occupancy helpers to choose a block size.

Stage 12 fills these compatibility holes without claiming full CUDA runtime
coverage.

## 3. FUNCTIONAL SCOPE
Implement and test:

### 3.1 Device management
* `cudaGetDeviceCount`
* `cudaGetDevice`
* `cudaSetDevice`
* `cudaGetDeviceProperties`
* `cudaDeviceReset`

Contract:
* Apple Silicon is exposed as one logical CUDA device.
* Device `0` is valid; any other device ID fails with `cudaErrorInvalidDevice`.
* `cudaDeviceReset` synchronizes outstanding work, clears runtime-visible errors,
  and keeps MCU usable for subsequent calls.

### 3.2 Device properties
Add a conservative `cudaDeviceProp` struct with fields commonly used by CUDA
host code:

* `name`
* `totalGlobalMem`
* `sharedMemPerBlock`
* `regsPerBlock`
* `warpSize`
* `maxThreadsPerBlock`
* `maxThreadsDim[3]`
* `maxGridSize[3]`
* `multiProcessorCount`
* `clockRate`
* `memoryClockRate`
* `memoryBusWidth`
* `major`
* `minor`
* `integrated`
* `unifiedAddressing`
* `managedMemory`
* `concurrentKernels`
* `asyncEngineCount`

Values must be truthful or conservative. Unsupported NVIDIA-specific fields must
not overclaim performance. `warpSize` is reported as CUDA logical 32 for
compatibility, while Stage 14 owns physical SIMD/warp semantics.

### 3.3 Runtime error API
* `cudaGetLastError`
* `cudaPeekAtLastError`
* `cudaGetErrorString`

Contract:
* `cudaPeekAtLastError` returns the current error without clearing it.
* `cudaGetLastError` returns and clears the current error.
* successful calls clear the last error only when CUDA normally reports success
  for that API family; diagnostics must stay useful.

### 3.4 Events
* `cudaEventCreate`
* `cudaEventCreateWithFlags`
* `cudaEventRecord`
* `cudaEventSynchronize`
* `cudaEventElapsedTime`
* `cudaEventDestroy`

Supported flags:
* `cudaEventDefault`
* `cudaEventBlockingSync`

Unsupported flags:
* `cudaEventDisableTiming`
* `cudaEventInterprocess`

Contract:
* recording an event captures all work already submitted to the selected stream;
* synchronizing an event waits for that captured stream work;
* elapsed time reports milliseconds between completed records;
* destroying a recorded event is safe after synchronizing captured work;
* invalid/unrecorded events fail with CUDA-like error codes.

### 3.5 Occupancy helper
Implement a conservative subset of:

* `cudaOccupancyMaxPotentialBlockSize`

Contract:
* accepts a kernel function pointer, dynamic shared memory, and block-size limit;
* returns a block size that does not exceed MCU's supported threadgroup limit;
* returns a minimum grid size of at least one;
* does not promise NVIDIA occupancy equivalence.

### 3.6 Memory edge cases
Refine:

* `cudaMemcpyDefault` inference;
* zero-size `cudaMemcpy`, `cudaMemcpyAsync`, and `cudaMemset`;
* invalid pointers and invalid copy kinds;
* metrics for runtime state APIs and events.

## 4. TEST PLAN
Add focused native tests:

* device count/properties smoke test;
* valid and invalid `cudaSetDevice`;
* `cudaPeekAtLastError` vs `cudaGetLastError`;
* event timing around async copies and kernels;
* event invalid flags and invalid handles;
* occupancy helper returns conservative usable geometry;
* zero-size memory operations stay successful where CUDA allows them.

Add checker coverage after focused tests:

* runtime API easy case;
* event timing medium case;
* occupancy/device properties hard case.

## 5. ACCEPTANCE
* Existing Stage 1-11 verification remains green.
* A CUDA file using supported `cuda_runtime.h` APIs and no auxiliary libraries
  compiles and runs through `mcu compile` without source edits.
* Device properties are conservative and stable enough for launch selection.
* Events time real queued work and report metrics.
* Unsupported runtime APIs or flags fail explicitly.
* Stage 13 capability reporting can consume a single runtime API registry.

## 6. NON-GOALS
* Warp intrinsics and CUDA Graphs; these remain Stage 14.
* External library expansion beyond Stage 11 cuBLAS SGEMM.
* Multi-GPU behavior.
* NVIDIA-equivalent occupancy math.
* Performance optimization beyond avoiding unnecessary synchronization.

## 7. EXPECTED COMPATIBILITY IMPACT
Before Stage 12, MCU is usable for many kernel-centric programs but fails on
common runtime scaffolding. After Stage 12, CUDA programs without auxiliary
libraries but with ordinary device queries, timing, and cleanup should require
fewer source edits.

Expected practical compatibility for CUDA code without warp/graph/texture:
roughly 70-80 percent, assuming the device code itself uses supported language
features.

## 8. IMPLEMENTATION REPORT - 2026-06-26
Implemented:

* `cudaDeviceProp` and conservative Apple Silicon property reporting;
* `cudaGetDeviceCount`, `cudaGetDevice`, `cudaSetDevice`,
  `cudaGetDeviceProperties`, and `cudaDeviceReset`;
* `cudaPeekAtLastError` with non-clearing semantics;
* `cudaEventCreate`, `cudaEventCreateWithFlags`, `cudaEventRecord`,
  `cudaEventSynchronize`, `cudaEventElapsedTime`, and `cudaEventDestroy`;
* conservative templated `cudaOccupancyMaxPotentialBlockSize`;
* runtime API frontend stubs for semantic probing;
* host transformation for runtime-only `cuda_runtime.h` programs;
* CUDA checker cases 21-23 for device properties, events, and error behavior;
* MCU version 0.12.0 and runtime ABI 5.

The event implementation is correctness-first: `cudaEventRecord` synchronizes
the captured stream before timestamping. This preserves deterministic semantics
for supported code. Lower-overhead event recording can be optimized later without
changing the public API.

Local verification in the current tool session:

* focused Stage 1/2/4/10/11/12 tests: 19 passed, 4 skipped because no Metal
  device was exposed to that session;
* runtime Objective-C++ syntax check passed;
* CUDA checker case 23 passed without requiring Metal initialization.
