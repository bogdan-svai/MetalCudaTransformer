# BabelStream attribution

This standalone dot-product workload uses the reduction operation associated
with BabelStream, created by Tom Deakin, Simon McIntosh-Smith and the University
of Bristol HPC group and based on John D. McCalpin's STREAM benchmark.

It is an MCU compatibility workload, not an official conforming BabelStream
implementation or result. Upstream license and run rules:
https://github.com/UoB-HPC/BabelStream
