# BabelStream attribution

This CUDA Core workload uses the Copy, Mul, Add and Triad operation set and
measurement conventions associated with BabelStream, created by Tom Deakin,
Simon McIntosh-Smith and the University of Bristol HPC group and based on John
D. McCalpin's STREAM benchmark.

The source in this directory is an MCU compatibility variant. Results produced
by it must not be described as official or conforming BabelStream results.
Upstream source, license and run rules: https://github.com/UoB-HPC/BabelStream
